# 实时 Agent 流与中部终端布局设计

## 目标
- 消息、思考过程、工具调用和工具结果在事件到达时立即更新，不依赖刷新页面。
- 删除后端与前端的人工逐字延迟，保留 SSE 事件持久化和任务重放。
- 终端只占中间编辑区域，左右侧栏不被终端高度挤压。
- 终端高度可通过水平拖拽条调整，并在打开和调整后自动适配 xterm 尺寸。

## 数据流
模型 provider 原始流式片段直接进入 AgentLoopEngine。思考片段发送 THINK_DELTA，文本片段发送 FINAL_DELTA；不再二次切分或 sleep。工具调用和观察结果继续使用 TOOL_CALL 与 OBSERVE。前端直接修改当前响应消息，并在 nextTick 后滚动，不使用每秒 80 字符的展示定时器。

## 布局
ws-body 保持三列：左侧文件树、中间 workspace-center、右侧 Agent 面板。workspace-center 内部垂直排列编辑器、终端拖拽条和终端面板。终端高度受最小值、最大值和中间区域可用高度限制。

## 安全与兼容
- 不改变鉴权、项目所有权、终端 WebSocket 协议或模型配置协议。
- 不增加依赖。
- 保留历史事件重放和 FINAL 全量内容作为最终一致性校正。
